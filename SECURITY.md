# Security Policy

This policy covers the ZipViz Registry API specification in this repository.

## Reporting a vulnerability

Please report suspected vulnerabilities **privately**. Do not open a public issue or pull
request.

- Report through the affected repository's **Security** tab, using
  [**Report a vulnerability**](https://github.com/ZipViz/zipviz-openapi/security/advisories/new)
  (GitHub private vulnerability reporting). The report stays private between you and
  the maintainers.
- We follow coordinated disclosure: we will acknowledge your report and keep you updated
  through remediation.

## Supported versions

Only the latest 1.x release of the spec receives security fixes.
